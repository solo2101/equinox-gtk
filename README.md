# Equinox GTK

Modernization project for the original Equinox 1.50 GTK2 theme engine, targeting Fedora Linux and MATE.

## Upstream

Original Equinox modifications by Matthieu James. See the upstream `AUTHORS`, `COPYING`, and `ChangeLog` files in the Equinox 1.50 source distribution. The original source is GPL-2.0 licensed.

## Plan

1. Import the original Equinox 1.50 source unchanged.
2. Preserve the original code on a `legacy` branch.
3. Test GTK2 compilation on Fedora 43.
4. Develop separate GTK3/GTK4 visual implementations while retaining the original appearance.

The original source import is still pending. Do not treat this initial commit as the imported engine.
